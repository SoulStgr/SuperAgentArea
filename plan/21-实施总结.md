## 2. 交付能力

- **多实例来源**：`<kind>:<key>`，folder 多路径、GitHub 多仓库/账号；按实例轮询、健康条目、统计、配置与迁移（旧 bare-kind 数据兼容，Thread 键 `folder:ops:demo-1.md` 新旧同串）。
- **项目归属前置**：实例默认归属 → 事件提示（`PROJECT.md`、`[项目]` 名、飞书标题、仓库映射）→ 注册表匹配；未命中走 `needsProject`（Eval 拒绝 + 提问 + 回答重评），agent 可提案、人确认才建站；路径/仓库校验与指定人审计。
- **汇报人/@提及**：默认发布者，评估提取提及（校验来源人员），建单回传工单卡并 @；GitHub `@login`、飞书 `<at>`、folder 写名字/QUESTION.md。
- **目录模型**：`<stateDir>/area/`（`workspace/`、`<station>/`、`<station>.work/`），成果提升与副本分离；仓库站 worktree 与分支规划在设计中（执行器扩展留后续）。
- **三个新页面**：工单源（实例卡/统计/添加来源/未归属回答）、工作站（卡片/六段/新建归档/项目配置/agent 段：历史 + 项目会话）、产物（列表/过滤/下载/反查链/打开 worker）。
- **一级页收口**：概览/工单源/工作站/产物/提示词/策略 + 设置齿轮；策略页三段（规则与准入/评估设置/最近决定）。
- **项目会话**：`project-<id>` 懒创建（cwd=项目 scratchDir），历史（工单/产物/报告）在 agent 段展示。

## 4. 已知限制（未在 P6 收口）

1. **具名实例的保存**不触发该实例账号检查/重启（启动与「重新检查」时校验；P1b 遗留 #2）。
2. **assessment 仓库资源读取**仍走 deployment 默认仓库（具名 GitHub 实例的轮询/PR/回复已按实例作用域）。
3. 实例级 Setup 问题不进服务脚本 `status` 的 exit 3（面板与实例健康可见）。
4. **深链**（URL hash）未做；面板路由仍是 sessionStorage。
5. 无「删除来源」（只支持禁用）；项目目录不可迁移。
6. 产物无版本/回收站；`KV.artifacts` 仅迁移读取。
7. 仓库站的 worktree/分支执行与合并流程仍在设计（建站与地址校验已具备）。

## 5. 建议的下一步（新需求）

1. **IM/远程源**：钉钉（Stream）、QQ 官方 bot、SFTP、S3/OSS；沿用 SourceKind 扩展 + 工单源页添加流程。
2. **仓库站执行**：每工单 worktree + `saa/<ticketId>` 分支与合并策略。
3. **生产线**：worker 提示词/技能实现 理解→规划→dry-run→特性分发→并行验收（融合文档 L2）。
4. **治理**：Watchdog 四门禁、Mandate 预算/租约、安全加固（架构文档阶段 4）。
5. **知识池**：KnowledgeEntry + 归档回填 + 检索（阶段 5）。
6. **收尾项**：每实例账号模型、assessment 读取按实例、深链、删除来源、产物版本。
