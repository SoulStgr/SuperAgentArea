# 阶段 1 E2E 手册：投件 → 建单 → Worker → 文件交付 → 通知

> 前置：桌面 profile 已卸载旧 dsh-superagent；本仓库已 `pnpm check` 全绿并包含 folder Source + Artifact 交付；GitHub 部署可选改造已合入（无 gh CLI 也能 setup 成功）。

## 1. 打包与安装

```powershell
cd H:\DTB_AIToos\superAgent\dsh-superagent-fusion
& $node $pnpm pack                      # 产出 dsh-superagent-0.1.0.tgz
Copy-Item .\dsh-superagent-0.1.0.tgz 'C:\Users\21973\.dsh\profiles\desktop\vendor\dsh-superagent-0.1.0.tgz' -Force
```

- 安装：`plugin_manager install_bundle` target 用 `file:vendor/dsh-superagent-0.1.0.tgz`（与旧安装同形态）。
- profile patch 需要启用 folder 源（bundle 内默认 disabled）：

```yaml
- id: dsh-superagent-folder
  disabled: false
```

- profile patch 已含 `- id: dsh-superagent` 的 `stateDir: C:\Users\21973\.dsh\state\superagent-desktop`（沿用旧状态目录，schema 迁移自动执行）。

## 2. 配置 folder Source（管理 API，loopback）

管理端前缀：`http://127.0.0.1:2341/orchestrator/api/`，请求头需 `x-orchestrator-request: 1`（同源校验）。

1. `GET settings` → 取 `source:folder` 与 `policy` 块的当前 `revision` 与 `value`。
2. `PUT settings/source:folder`：
   ```json
   { "value": { "enabled": true, "config": { "folders": [ { "id": "ops",
       "inbox": "H:\\DTB_AIToos\\superAgent\\e2e\\inbox",
       "outbox": "H:\\DTB_AIToos\\superAgent\\e2e\\outbox" } ],
       "operator": "21973", "pollSeconds": 5 } },
     "revision": <当前 revision> }
   ```
3. `PUT settings/policy`：在现有 policy 值上追加 `sources.folder.allowed = [{ "id": "21973" }]`（operator 必须列入，否则投件只会被过滤）。
4. `POST setup/check` 或等待 setup 完成；`GET sources` 确认 folder 健康为 `ready`。

## 3. 投件与验收

```powershell
Set-Content 'H:\DTB_AIToos\superAgent\e2e\inbox\demo-1.md' `
  '请在 deliver/ 目录写一个 hello.txt，内容为 "hello from folder"，然后报告 ready。'
```

验收（轮询最多 ~5 分钟，Worker 是真 LLM Session）：

| 断言 | 方式 |
|---|---|
| 生成工单 | `GET tickets` 出现标题含 `demo-1` 的工单 |
| Worker 执行 | `GET tickets/:id` 出现 assignment 与 report |
| 产物交付 | `H:\DTB_AIToos\superAgent\e2e\outbox\<ticketId>\artifacts\hello.txt` 存在且内容正确 |
| 通知 | outbox 下出现结果回复 `.md`（含产物清单与 `Delivered to:` 路径） |

## 4. 失败排查

- `GET state` / `GET overview`：setup 问题、执行器暂停、模型配置
- `GET sources`：folder 健康 detail（setupPending/sourceOff/pollFailures）
- 药丸：worker 的模型默认取 profile 的 `agent-default-model`；folder 工单的 worker 可能无 GitHub 环境变量，属预期
