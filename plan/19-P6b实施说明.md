# 19 P6b 实施说明：界面收口（Prompts/Policy 一级页 + 设置齿轮 + 标签收敛）

> 前置：P1–P6a 完成，0.2.1 已装（HEAD `12f71b3`，`pnpm check` 绿 · 1276/14）。
> 依据：用户决策「Prompts/Policy 提升为一级页」；[10-工作站与产物设计方案.md](10-工作站与产物设计方案.md) §5.2；[UI-审查报告.md](UI-审查报告.md) §5。
> 范围：**Tabs 收敛 + Prompts/Policy 一级页 + 设置齿轮 + 设置页瘦身 + 修 P6a 遗留的 workspace 历史计数不一致**。不做 P6c（实例级健康、具名 Setup、KV 删除、深链）。

---

## 1. 目标导航

```
概览 Overview
工单源 Sources
工作站 Workstations
产物 Artifacts
提示词 Prompts        ← 由设置内提升
策略 Policy & Eval    ← 由「评估」Tab + 设置内 Policy/Eval 合并提升
（header 齿轮）设置 Settings  ← 不再是 Tab
```

- `TABS = ['overview','source','workstations','artifacts','prompts','policy']`。
- **详情路由保留**（不进 TABS）：`{page:'execution', id}` 工单详情、`{page:'trigger', id}` 线程详情、`{page:'tickets'|'trigger'|'eval'|'settings'}` 作为内部可达页（不再有 Tab 入口，除 settings 由齿轮进入）。`parseRoute` 继续兼容旧值，防止刷新丢失。
- 搜索/链接可以继续跳工单、线程、策略历史等详情。

## 2. 页面

### 2.1 提示词页（一级）

- 复用现有 `src/client/prompts.tsx` 的编辑/完整提示词/历史三视，作为 `{page:'prompts'}` 的页面内容；不再嵌在设置内。
- 需要 `SettingsProvider` 时按现有方式提供（页面级包裹），保存条/冲突/默认更新语义不变。
- 页头标题「提示词」，不重复设置分组导航。

### 2.2 策略页（一级）

- 组合：**策略版本 + 规则列表 + 准入表**（现有 `PolicyBlock`）、**评估设置**（模式/超时/模型，现有 `EvalBlock`）、**最近决定**（现有 `EvalStatus` 决策日志，含强度/原因/策略版本）。
- 页内分段（segmented）：「规则与准入」「评估设置」「最近决定」，不叠 Tab。
- 保存仍走现有 settings block（policy/eval）与 revision 机制。

### 2.3 设置页（齿轮）

- `TABS` 移除 `settings`；header 增加齿轮按钮（`Icon` 新增 `settings` 图标或复用现有图标集），点击 `navigate({page:'settings'})`。
- 设置页保留分组：**执行器/执行环境**、**部署（机器上限/账号派生值/状态目录）**；移除「来源」「评估」「提示词」三组（已迁移/提升）。
- 设置页内部左导航保留两组；`lastSettingsGroup` 兼容旧组名（source/eval/prompts 回退到 execution）。

### 2.4 其他页面的入口调整

- 工单源/工作站/产物/概览中的链接不受影响；「评估」Tab 移除后，概览的系统问题/决策链接指向策略页的决定段。
- 工单详情、线程详情中的跨页链接保持。

## 3. 修 P6a 遗留（workspace 计数一致）

- P4 的项目列表/详情计数用 `artifact.project = 'prj_workspace'`，而 P6a 历史把 `project IS NULL` 的旧产物算进 workspace；统一为：**workspace 的计数也包含 `project IS NULL` 的旧行**（列表/详情/分页一致），避免卡片、详情、历史三处数字不一致。
- 工单同理：旧工单 `projectId` 为空（迁移已回填 prj_workspace，理论上无），保持一致处理。

## 6. 验收

`pnpm check` exit 0；手动路径（测试夹具验证）：
1. 顶部只剩六个 Tab；齿轮进入设置，只有执行器/部署两组；
2. 提示词页可编辑/预览/历史并保存；
3. 策略页三段可切换，规则保存/评估设置保存/决定列表正常；
4. 旧链接（工单/线程/设置）仍能打开，刷新后路由不丢；
5. workspace 卡片、详情、项目历史三处产物/工单数一致。
