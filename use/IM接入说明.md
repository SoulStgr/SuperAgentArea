# IM 接入说明（钉钉 / QQ / 微信）

三个 IM 来源都已在「设置 → 工单源」里，但目前**钉钉/QQ 是手动填凭据**，微信是**扫码登录个人号**。下面分别说明怎么填，以及「扫码创建机器人」的可行性与要求。

---

## 钉钉（手动 Client ID/Secret）

1. 在钉钉开放平台创建**企业内部应用**，添加机器人能力，开通「机器人消息」相关权限。
2. 拿到 **Client ID（AppKey）**、**Client Secret（AppSecret）**、**RobotCode**（机器人编码）。
3. 面板：设置 → 工单源 → 钉钉 → 添加账号，填三项；可选 `allowedUserIds` 白名单（钉钉 staffId，逗号分隔）。
4. 保存后走 **Stream 长连接**（不需要公网回调地址）：私聊直接触发，群聊必须 @ 机器人；回复用 sessionWebhook，过期走机器人 API。
5. 入站图片/文件会下载到 `area/attachments/dingtalk/...`；工单产物可回传为文件/图片（上限 10 个/20 MiB）。

**扫码创建机器人可以吗？** 可以，但需要额外开发：
- dsh-im 的钉钉渠道实现了「扫码登录/设备授权」流程（`device-auth.mjs`），可以按 MIT 复用；
- 需要钉钉开放平台的扫码建应用/授权能力，以及企业管理员权限；
- 流程：面板展示二维码 → 钉钉扫码授权 → 回调拿到临时凭据 → 换取 Client ID/Secret/RobotCode → 自动创建账号；
- 这条路径尚未实现；目前手动填三项即可用。

---

## QQ（手动 AppID/Secret）

1. 在 QQ 开放平台创建机器人，拿到 **AppID**、**AppSecret**；可先用沙箱环境。
2. 面板：设置 → 工单源 → QQ → 添加账号，填 AppID/AppSecret，可选沙箱、`allowedUserIds`。
3. 走机器人网关 WebSocket 长连接；私聊直接触发，群聊 @ 触发；只能**被动回复**（窗口外记 `gone`，不会转主动消息）。
4. 入站图片/文件下载到 `area/attachments/qq/...`；出站附件暂未实现。

**扫码创建机器人可以吗？** 受许可证限制，暂不建议：
- QQ 官方的扫码创建/绑定依赖 `@tencent-connect/qqbot-connector`，该包是 **UNLICENSED**，不能复制进本项目；
- 自行重写扫码协议风险高、协议可能变化；
- 因此本项目保持「手动 AppID/AppSecret」，除非你接受把 dsh-im 作为依赖（当前明确不引入）。
- 要求（如果将来做）：QQ 开放平台开发者账号、机器人创建权限、手机 QQ 扫码、沙箱/正式环境审核。

---

## 微信（扫码登录个人号）

1. 准备一个**专用**个人微信号（不要用主号），手机在手。
2. 面板：设置 → 工单源 → 微信 → 添加账号并保存（无字段）。
3. 账号行点「扫码登录」→ 手机微信扫码 → 确认；token 存本机状态库，不写 settings。
4. 只接收**白名单私聊**：策略页 allowed 里加对方 `from_user_id`；群消息不支持（iLink 个人号通道没有群身份）。
5. 入站图片/文件会下载并 AES 解密到 `area/attachments/wechat/...`；回复只发文本。

**扫码创建机器人可以吗？** 微信这里扫码的是**个人号登录**，不是创建机器人；iLink 没有「创建机器人」的概念。群自动回复不可用，群场景请用企业微信应用/飞书/钉钉。

> 风险：个人号自动化可能被腾讯限制/封号，默认只建议专用号 + 小名单。

---

## 通用要求（扫码接入若要做）

- 平台开发者账号与相应权限（钉钉企业管理员、QQ 开放平台、微信 iLink）；
- 能够访问平台 HTTPS 接口（部分网络需要代理）；
- 二维码有效期与轮询（通常 2-5 分钟），过期要能刷新；
- 凭据存储：只存本机（settings/KV），不回传面板、不写日志；
- 回调/长连接：钉钉/QQ 用长连接，无需公网 IP；微信 iLink 用长轮询。
