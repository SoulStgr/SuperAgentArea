# IM 接入说明（钉钉 / QQ / 微信）

三个 IM 来源都已在「设置 → 工单源」里：**钉钉支持扫码接入**（扫码授权后自动创建账号）或手工填凭据；**QQ 目前只支持手工接入**（扫码接入开发中，Tab 置灰）；微信是**扫码登录个人号**。下面分别说明怎么填，以及「扫码创建机器人」的现状。

---

## 钉钉（扫码接入 / 手工接入）

1. 面板：设置 → 工单源 → 钉钉 → 添加账号，弹窗顶部有两个 Tab：
   - **扫码接入**（默认）：点「开始扫码」→ 面板显示二维码 → 用钉钉扫码并在手机上确认授权。确认后由服务端用拿到的 **Client ID / Client Secret** 自动创建并启用账号（显示名称「钉钉（扫码）」，Robot Code 缺省用 AppKey）。二维码 10 分钟内有效，过期可刷新。
   - **手工接入**：先按弹窗里的创建入口与步骤，在钉钉开放平台创建**企业内部应用**、给应用添加**机器人**能力并选 **Stream 模式**，拿到 **Client ID（AppKey）**、**Client Secret（AppSecret）**、**RobotCode**；然后在弹窗里填这三项并创建。
2. 扫码拿到的凭据只落在本机设置里：Client Secret 不返回浏览器、不写日志、不进健康详情和工单。
3. 保存后走 **Stream 长连接**（不需要公网回调地址）：私聊直接触发，群聊必须 @ 机器人；回复用 sessionWebhook，过期走机器人 API。
4. 入站图片/文件会下载到 `area/attachments/dingtalk/...`；工单产物可回传为文件/图片（上限 10 个/20 MiB）。

> 扫码接入走钉钉开放平台的设备授权（device registration）流程，和 dsh-im 的 `device-auth.mjs` 是同一协议（MIT，见 `THIRD_PARTY_NOTICES.md`）。没有应用创建权限、或企业不允许设备授权时，请用手工接入。

---

## QQ（手工接入，扫码接入开发中）

1. 面板：设置 → 工单源 → QQ → 添加账号。弹窗有两个 Tab：**扫码接入（开发中）** 目前禁用，**手工接入** 按下面的步骤填。
2. 在 [QQ 开放平台](https://q.qq.com/) 创建机器人并完成开发者验证；在「开发管理」复制 **AppID**，生成/查看 **AppSecret**。
3. 测试期可先在面板勾选「沙箱环境」，用沙箱凭据跑通；正式上线前再关掉沙箱并完成审核。
4. 面板：填 AppID/AppSecret，可选沙箱、`allowedUserIds`，创建账号；走机器人网关 WebSocket 长连接，私聊直接触发，群聊 @ 触发；只能**被动回复**（窗口外记 `gone`，不会转主动消息）。
5. 入站图片/文件下载到 `area/attachments/qq/...`；出站附件暂未实现。

**扫码接入为什么没做？** QQ 官方的扫码创建/绑定依赖 `@tencent-connect/qqbot-connector`，该包是 **UNLICENSED**，不能复制进本项目，也不能新增该依赖；自行重写扫码协议风险高、协议还可能变化。因此本项目保持手工接入，等官方授权组件可用或协议明确后再补。

---

## 微信（扫码登录个人号）

1. 准备一个**专用**个人微信号（不要用主号），手机在手。
2. 面板：设置 → 工单源 → 微信 → 添加账号并保存（无字段）。
3. 账号行点「扫码登录」→ 手机微信扫码 → 确认；token 存本机状态库，不写 settings。
4. 只接收**白名单私聊**：策略页 allowed 里加对方 `from_user_id`；群消息不支持（iLink 个人号通道没有群身份）。
5. 入站图片/文件会下载并 AES 解密到 `area/attachments/wechat/...`；回复只发文本。

**扫码创建机器人可以吗？** 微信这里扫码的是**个人号登录**，不是创建机器人；iLink 没有「创建机器人」的概念。群自动回复不可用，群场景请用企业微信应用/飞书/钉钉。

> 风险：个人号自动化可能被腾讯限制/封号，默认只建议专用号 + 小名单。

---

## 通用要求（扫码接入）

- 平台开发者账号与相应权限（钉钉企业管理员或应用创建权限、QQ 开放平台、微信 iLink）；
- 能够访问平台 HTTPS 接口（部分网络需要代理）；
- 二维码有效期与轮询（钉钉扫码 10 分钟、微信登录 5 分钟，QQ 若将来支持一般为 2-5 分钟），过期要能刷新；
- 凭据存储：只存本机（settings/KV），不回传面板、不写日志；
- 回调/长连接：钉钉/QQ 用长连接，无需公网 IP；微信 iLink 用长轮询。
